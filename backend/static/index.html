Code Scanner

How to use
① Paste a GitHub repo URL and click Scan
② Public repos — no token needed
③ Private repos — paste your GitHub token below
To get a token: github.com/settings/tokens → Generate new token (classic) → tick repo → copy it
🔒 Private repo? How to get a token?
Getting a GitHub Personal Access Token takes 1 minute:
  1. Go to github.com/settings/tokens
  2. Click Generate new token (classic)
  3. Give it any name (e.g. ai-code-scanner)
  4. Tick the repo checkbox (full repo access)
  5. Click Generate token at the bottom
  6. Copy the token (starts with ghp_) and paste it above
The token is only used to clone your repo and is never stored anywhere.
